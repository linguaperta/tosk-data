# The present tense

Find the **stem**: take the infinitive and remove *-en* (*werken → werk*). Then:

| | werken (to work) | lopen (to walk) | zitten (to sit) |
|---|---|---|---|
| ik | werk | loop | zit |
| jij / je | werk**t** | loop**t** | zit |
| hij / zij / het | werk**t** | loop**t** | zit |
| wij / we | werk**en** | lop**en** | zitt**en** |
| jullie | werk**en** | lop**en** | zitt**en** |
| zij / ze | werk**en** | lop**en** | zitt**en** |

- **ik** = stem; **jij, hij/zij/het, u** = stem + **t**; **plural** = the infinitive.
- Spelling of the stem: keep a long vowel long (*lopen → loop*, *maken → maak*, *eten → eet*), write one consonant at the end instead of two (*zeggen → zeg*, *zitten → zit*), and end in *f* / *s* instead of *v* / *z* (*leven → leef*, *lezen → lees*).
- A stem that already ends in *t* gets no extra *t*: *ik zit, jij zit, hij zit*.
- Inversion: when *jij/je* comes after the verb, the *-t* disappears: *Jij werkt.* → *Werk jij vandaag?* (but *Werkt hij vandaag?*).
- The present also covers "am doing" and plans: *Ik werk nu.* *Morgen werk ik thuis.*
