# Verleden tijd: sterke en onregelmatige werkwoorden

Sterke werkwoorden veranderen in de verleden tijd van **klinker** en krijgen in het enkelvoud geen uitgang; het meervoud krijgt **-en**. Ook een paar veelgebruikte zwakke werkwoorden zijn onregelmatig. Deze vormen moet je uit je hoofd leren.

| infinitief | enkelvoud (ik/jij/hij) | meervoud (wij/jullie/zij) |
|---|---|---|
| zijn | was | waren |
| hebben | had | hadden |
| gaan | ging | gingen |
| komen | kwam | kwamen |
| zien | zag | zagen |
| doen | deed | deden |
| geven | gaf | gaven |
| nemen | nam | namen |
| blijven | bleef | bleven |
| vinden | vond | vonden |
| krijgen | kreeg | kregen |
| worden | werd | werden |
| kunnen / mogen / moeten | kon / mocht / moest | konden / mochten / moesten |
| zeggen / denken / brengen | zei / dacht / bracht | zeiden / dachten / brachten |

- Veelvoorkomende klinkerpatronen: *ij → ee* (*blijven → bleef, krijgen → kreeg*), *ie → oo* (*kiezen → koos*), *i → o* (*vinden → vond, beginnen → begon*), *e → a* (*geven → gaf, nemen → nam*).
- De spelling van het meervoud volgt de klinker: *gaf → gaven, nam → namen, kwam → kwamen*.
- *Was* en *had* hoor je in de spreektaal voortdurend: *Ik was moe.* *We hadden geen tijd.*
- *Zou / zouden* (van *zullen*) betekent "would": *Ik zou graag komen.*
