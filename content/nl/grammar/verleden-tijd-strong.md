# Simple past: strong and irregular verbs

Strong verbs change their **vowel** in the simple past and get no ending in the singular; the plural adds **-en**. A few common weak verbs are irregular too. Learn these forms by heart.

| infinitive | singular (ik/jij/hij) | plural (wij/jullie/zij) |
|---|---|---|
| zijn (to be) | was | waren |
| hebben (to have) | had | hadden |
| gaan (to go) | ging | gingen |
| komen (to come) | kwam | kwamen |
| zien (to see) | zag | zagen |
| doen (to do) | deed | deden |
| geven (to give) | gaf | gaven |
| nemen (to take) | nam | namen |
| blijven (to stay) | bleef | bleven |
| vinden (to find) | vond | vonden |
| krijgen (to get) | kreeg | kregen |
| worden (to become) | werd | werden |
| kunnen / mogen / moeten | kon / mocht / moest | konden / mochten / moesten |
| zeggen / denken / brengen | zei / dacht / bracht | zeiden / dachten / brachten |

- Common vowel patterns: *ij → ee* (*blijven → bleef, krijgen → kreeg*), *ie → oo* (*kiezen → koos*), *i → o* (*vinden → vond, beginnen → begon*), *e → a* (*geven → gaf, nemen → nam*).
- Spelling of the plural follows the vowel: *gaf → gaven, nam → namen, kwam → kwamen*.
- *Was* and *had* are used in speech all the time: *Ik was moe.* *We hadden geen tijd.*
- *Zou / zouden* (from *zullen*) means "would": *Ik zou graag komen.*
