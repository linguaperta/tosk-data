# De tegenwoordige tijd

Zoek de **stam**: neem het hele werkwoord en haal *-en* weg (*werken → werk*). Dan:

| | werken | lopen | zitten |
|---|---|---|---|
| ik | werk | loop | zit |
| jij / je | werk**t** | loop**t** | zit |
| hij / zij / het | werk**t** | loop**t** | zit |
| wij / we | werk**en** | lop**en** | zitt**en** |
| jullie | werk**en** | lop**en** | zitt**en** |
| zij / ze | werk**en** | lop**en** | zitt**en** |

- **ik** = stam; **jij, hij/zij/het, u** = stam + **t**; **meervoud** = het hele werkwoord.
- Spelling van de stam: een lange klank blijft lang (*lopen → loop*, *maken → maak*, *eten → eet*), aan het eind één medeklinker in plaats van twee (*zeggen → zeg*, *zitten → zit*), en *f* / *s* in plaats van *v* / *z* (*leven → leef*, *lezen → lees*).
- Eindigt de stam al op een *t*, dan komt er geen *t* bij: *ik zit, jij zit, hij zit*.
- Inversie: staat *jij/je* achter het werkwoord, dan valt de *-t* weg: *Jij werkt.* → *Werk jij vandaag?* (maar: *Werkt hij vandaag?*).
- De tegenwoordige tijd gebruik je ook voor iets wat nu bezig is en voor plannen: *Ik werk nu.* *Morgen werk ik thuis.*
