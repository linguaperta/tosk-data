# Object pronouns

After a verb or a preposition Dutch uses object forms: *Ik zie **hem**.* (I see him.) *Dit is voor **jou**.* (This is for you.) Most have a stressed and an unstressed form; the unstressed one is far more common in speech.

| subject | object (stressed) | object (unstressed) |
|---|---|---|
| ik | mij | me |
| jij / je | jou | je |
| u | u | u |
| hij | hem | ('m) |
| zij / ze (she) | haar | ('r) |
| het | het | ('t) |
| wij / we | ons | ons |
| jullie | jullie | je |
| zij / ze (they) | hen, hun | ze |

- *Hen* is used after a preposition and as a direct object (*met hen, ik ken hen*), *hun* for "to them" (*Ik geef hun een boek*). In speech *ze* covers both: *Ik ken ze.*
- Use the stressed forms for emphasis or contrast: *Hij ziet **mij**, niet jou.*
- **zich** is the reflexive "himself, herself, themselves": *Hij wast zich.* For the other persons use *me, je, ons*: *Ik was me.* Stressed: *mezelf, jezelf, zichzelf*.
- **elkaar** = each other: *We zien elkaar morgen.*
- *Haar* and *ons* are also possessives (her, our); see the possessives skill.
