# Scheidbare werkwoorden

Veel Nederlandse werkwoorden bestaan uit een **partikel** plus een werkwoord: *op + staan = opstaan*, *terug + komen = terugkomen*. In een hoofdzin blijft de persoonsvorm op de tweede plaats en gaat het partikel naar het **eind** van de zin.

| | opstaan | meenemen |
|---|---|---|
| ik | sta ... op | neem ... mee |
| jij / je | staat ... op | neemt ... mee |
| hij / zij / het | staat ... op | neemt ... mee |
| wij / jullie / zij | staan ... op | nemen ... mee |

- *Ik sta elke dag om zeven uur **op**.* *Neem je een paraplu **mee**?* *Hij komt morgen **terug**.*
- In een bijzin en als infinitief blijft het werkwoord bij elkaar: *... omdat ik vroeg **opsta**.* *Ik wil vroeg **opstaan**.*
- Met *te* en in het voltooid deelwoord staat het partikel vooraan: *op te staan*, *opgestaan*, *meegenomen*, *teruggekomen*.
- De klemtoon ligt op het partikel: **OP**staan, **MEE**nemen. Werkwoorden die beginnen met *be-, ge-, her-, ver-, ont-* zijn nooit scheidbaar (*vertellen, begrijpen*).
- Veelvoorkomende partikels: *aan, af, binnen, mee, na, op, terug, uit, weg, thuis, voor*.
