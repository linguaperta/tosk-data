# Het perfectum met hebben

Het perfectum (voltooid tegenwoordige tijd) is in gesproken Nederlands de gewone manier om over het verleden te praten. De meeste werkwoorden maken het met de tegenwoordige tijd van **hebben** plus een **voltooid deelwoord**, dat achteraan de zin staat: *Ik heb gisteren hard gewerkt.*

| | werken | zien |
|---|---|---|
| ik | heb gewerkt | heb gezien |
| jij / je | hebt gewerkt | hebt gezien |
| hij / zij / het | heeft gewerkt | heeft gezien |
| wij / jullie / zij | hebben gewerkt | hebben gezien |

Voltooid deelwoord van regelmatige werkwoorden: **ge + stam + t of d**.

- Een **t** als de laatste letter van de stam in *'t kofschip* zit (t, k, f, s, ch, p): *werken → gewerkt*, *maken → gemaakt*, *koken → gekookt*. Anders een **d**: *horen → gehoord*, *spelen → gespeeld*.
- Kijk bij *v* en *z* naar het hele werkwoord: die krijgen een **d** (*leven → geleefd*, *reizen → gereisd*).
- Geen *ge-* als het werkwoord begint met *be-, ge-, her-, ver-, ont-, er-*: *betalen → betaald*, *vertellen → verteld*, *gebruiken → gebruikt*.
- Onregelmatige (sterke) werkwoorden eindigen op **-en**, vaak met een andere klinker: *zien → gezien*, *nemen → genomen*, *geven → gegeven*, *doen → gedaan*, *hebben → gehad*. Sommige eindigen op -t: *denken → gedacht*, *brengen → gebracht*, *zeggen → gezegd*.
