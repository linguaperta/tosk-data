# Possessives

Dutch possessives do not change for de- or het-words, except *ons / onze*.

| | possessive | example |
|---|---|---|
| ik | mijn (m'n) | mijn boek, mijn moeder |
| jij / je | jouw, je | jouw huis, je fiets |
| u | uw | uw paspoort |
| hij / het | zijn (z'n) | zijn auto |
| zij / ze (she) | haar | haar tas |
| wij / we | ons (het-word) / onze (de-word, plural) | ons huis, onze tuin, onze kinderen |
| jullie | jullie, je | jullie school |
| zij / ze (they) | hun | hun ouders |

- **ons** is only used with a singular het-word: *ons huis*, but *onze stad*, *onze huizen*.
- *Jouw* is the stressed form; *je* is the normal unstressed one: *Is dit je jas?* — *Nee, dat is jouw jas, niet de mijne.*
- Without a noun: *Dat boek is van mij / van jou / van hem.* (That book is mine / yours / his.) More formal: *het mijne, de jouwe*.
- Don't confuse *zijn* (his) with the verb *zijn* (to be), or *haar* (her) with *het haar* (hair).
