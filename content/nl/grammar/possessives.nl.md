# Bezittelijke voornaamwoorden

Nederlandse bezittelijke voornaamwoorden veranderen niet bij de- of het-woorden, behalve *ons / onze*.

| | bezittelijk vnw. | voorbeeld |
|---|---|---|
| ik | mijn (m'n) | mijn boek, mijn moeder |
| jij / je | jouw, je | jouw huis, je fiets |
| u | uw | uw paspoort |
| hij / het | zijn (z'n) | zijn auto |
| zij / ze (enkelvoud) | haar | haar tas |
| wij / we | ons (het-woord) / onze (de-woord, meervoud) | ons huis, onze tuin, onze kinderen |
| jullie | jullie, je | jullie school |
| zij / ze (meervoud) | hun | hun ouders |

- **ons** gebruik je alleen bij een enkelvoudig het-woord: *ons huis*, maar *onze stad*, *onze huizen*.
- *Jouw* is de beklemtoonde vorm, *je* de gewone onbeklemtoonde: *Is dit je jas?* — *Nee, dat is jouw jas, niet de mijne.*
- Zonder zelfstandig naamwoord: *Dat boek is van mij / van jou / van hem.* Formeler: *het mijne, de jouwe*.
- Verwar *zijn* (bezittelijk) niet met het werkwoord *zijn*, of *haar* (bezittelijk) met *het haar* op je hoofd.
