# Onregelmatige toekomende tijd: tendré, haré

Zo'n tien werkwoorden veranderen hun stam in de toekomende tijd. De uitgangen blijven gelijk (*-é, -ás, -á, -emos, -éis, -án*).

| infinitief | stam | yo |
|---|---|---|
| tener | **tendr-** | tendré |
| poner | **pondr-** | pondré |
| salir | **saldr-** | saldré |
| venir | **vendr-** | vendré |
| poder | **podr-** | podré |
| saber | **sabr-** | sabré |
| querer | **querr-** | querré |
| haber | **habr-** | habrá (er zal zijn) |
| hacer | **har-** | haré |
| decir | **dir-** | diré |

- Drie patronen: de *e/i* wordt **d** (*tendré, saldré*), de *e* valt weg (*podré, sabré, querré*), of een korte stam (*haré, diré*).
- Samenstellingen doen mee: *mantener → mantendré*, *suponer → supondré*, *deshacer → desharé*.
- *Habrá* = er zal/zullen zijn: *Mañana habrá mucha gente.*
