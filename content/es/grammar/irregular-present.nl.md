# Onregelmatige werkwoorden: tengo, hago, voy

Een paar heel gewone werkwoorden zijn onregelmatig. Veel ervan alleen in de **yo**-vorm:

| yo-vorm op -go | yo-vorm op -zco / anders |
|---|---|
| hacer → **hago** | conocer → **conozco** |
| poner → **pongo** | dar → **doy** |
| salir → **salgo** | ver → **veo** |
| traer → **traigo** | |

Andere veranderen meer:

| | tener | venir | decir | ir | oír |
|---|---|---|---|---|---|
| yo | tengo | vengo | digo | voy | oigo |
| tú | tienes | vienes | dices | vas | oyes |
| él / ella / usted | tiene | viene | dice | va | oye |
| nosotros | tenemos | venimos | decimos | vamos | oímos |
| vosotros | tenéis | venís | decís | vais | oís |
| ellos / ellas / ustedes | tienen | vienen | dicen | van | oyen |

- *Tener* gebruik je voor leeftijd en gevoelens waar het Nederlands "zijn" of "hebben" zegt: *Tengo veinte años.* (Ik ben twintig.) *Tengo hambre / frío / miedo.* (Ik heb honger / het koud / ben bang.)
- *Ir a* + plaats: *Voy a la playa.* (*Ir a* + infinitief komt in de volgende unit.)
- *Conocer* = kennen (een persoon of plaats); *saber* = weten.
