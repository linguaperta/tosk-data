# Estar: to be (where and how)

**Estar** is the other "to be". It says *where* something is and *how* it is right now: location, mood, health and states that can change.

| | estar |
|---|---|
| yo | estoy |
| tú | estás |
| él / ella / usted | está |
| nosotros | estamos |
| vosotros | estáis |
| ellos / ellas / ustedes | están |

- Location: *Estoy en casa.* *¿Dónde está el baño?*
- How you are: *¿Cómo estás? – Estoy bien.* *Ana está cansada.*
- Ser or estar? *Pedro es aburrido* (a boring person) / *Pedro está aburrido* (bored now). *La sopa es buena* (good soup) / *La sopa está buena* (tastes good).
- Mind the accents: *está* (is) vs *esta* (this), *estás* (you are) vs *estas* (these).
- **Hay** (from *haber*) means "there is / there are" and never changes: *Hay un perro en el jardín.* Use *estar* for a specific thing: *El perro está en el jardín.*
