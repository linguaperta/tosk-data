# Irregular futures: tendré, haré

About a dozen verbs change their stem in the future. The endings stay the same (*-é, -ás, -á, -emos, -éis, -án*).

| infinitive | stem | yo |
|---|---|---|
| tener | **tendr-** | tendré |
| poner | **pondr-** | pondré |
| salir | **saldr-** | saldré |
| venir | **vendr-** | vendré |
| poder | **podr-** | podré |
| saber | **sabr-** | sabré |
| querer | **querr-** | querré |
| haber | **habr-** | habrá (there will be) |
| hacer | **har-** | haré |
| decir | **dir-** | diré |

- Three patterns: the *e/i* becomes **d** (*tendré, saldré*), the *e* drops out (*podré, sabré, querré*), or a short stem (*haré, diré*).
- Compounds follow: *mantener → mantendré*, *suponer → supondré*, *deshacer → desharé*.
- *Habrá* = there will be: *Mañana habrá mucha gente.*
