# Wederkerende werkwoorden: me levanto

Wederkerende werkwoorden hebben een voornaamwoord dat terugwijst naar het onderwerp, zoals *zich* in het Nederlands. In het woordenboek eindigen ze op **-se**: *levantarse* (opstaan), *llamarse* (heten).

| | levantarse |
|---|---|
| yo | **me** levanto |
| tú | **te** levantas |
| él / ella / usted | **se** levanta |
| nosotros | **nos** levantamos |
| vosotros | **os** levantáis |
| ellos / ellas / ustedes | **se** levantan |

- Het voornaamwoord staat voor het vervoegde werkwoord, of plakt aan een infinitief of gerundio: *Me voy a duchar* = *Voy a ducharme*.
- Dagelijkse routine: *despertarse* (wakker worden), *levantarse*, *ducharse*, *lavarse* (zich wassen), *vestirse* (zich aankleden, *e → i*), *acostarse* (naar bed gaan, *o → ue*), *sentarse* (gaan zitten, *e → ie*).
- Veel werkwoorden krijgen met *se* een andere betekenis: *quedar* (afspreken) / *quedarse* (blijven); *ir* (gaan) / *irse* (weggaan); *llamar* (bellen, roepen) / *llamarse* (heten).
- Bij lichaamsdelen gebruik je het lidwoord, geen bezittelijk woord: *Me lavo las manos.* (Ik was mijn handen.)
- *Nos* en *se* kunnen ook "elkaar" betekenen: *Nos vemos mañana.* (Tot morgen.) *Se quieren mucho.*
- *Se* maakt ook onpersoonlijke zinnen: *Aquí se habla español.* (Hier spreekt men Spaans.)
- De oefeningen trainen de werkwoordsvormen; het voornaamwoord volgt de tabel hierboven.
