# Onregelmatige voltooide deelwoorden: hecho, dicho, visto

Een kleine groep veelgebruikte werkwoorden heeft een onregelmatig deelwoord. Leer ze uit je hoofd, want je komt ze overal tegen.

| infinitief | deelwoord | | infinitief | deelwoord |
|---|---|---|---|---|
| hacer | **hecho** | | abrir | **abierto** |
| decir | **dicho** | | escribir | **escrito** |
| ver | **visto** | | romper | **roto** |
| poner | **puesto** | | morir | **muerto** |
| volver | **vuelto** | | descubrir | **descubierto** |

- *¿Qué has hecho?* (Wat heb je gedaan?) *No he dicho nada.* *¿Has visto a Tom?*
- Afgeleide werkwoorden doen mee: *devolver → devuelto*, *suponer → supuesto*, *deshacer → deshecho*.
- Werkwoorden met een stam op een klinker krijgen een accent: *leer → leído*, *creer → creído*, *oír → oído*, *traer → traído*.
- Als bijvoeglijk naamwoord passen deze deelwoorden zich aan: *la puerta abierta*, *los libros escritos en inglés*.
