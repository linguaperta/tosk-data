# Irregular participles: hecho, dicho, visto

A small group of common verbs has an irregular participle. They are worth learning by heart, because they are everywhere.

| infinitive | participle | | infinitive | participle |
|---|---|---|---|---|
| hacer | **hecho** | | abrir | **abierto** |
| decir | **dicho** | | escribir | **escrito** |
| ver | **visto** | | romper | **roto** |
| poner | **puesto** | | morir | **muerto** |
| volver | **vuelto** | | descubrir | **descubierto** |

- *¿Qué has hecho?* (What have you done?) *No he dicho nada.* *¿Has visto a Tom?*
- Verbs built on them follow: *devolver → devuelto*, *suponer → supuesto*, *deshacer → deshecho*.
- Verbs whose stem ends in a vowel write an accent: *leer → leído*, *creer → creído*, *oír → oído*, *traer → traído*.
- Like adjectives these participles agree: *la puerta abierta*, *los libros escritos en inglés*.
