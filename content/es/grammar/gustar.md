# Me gusta: verbs like gustar

*Gustar* works the other way round from "to like": the thing you like is the **subject**, and the person is an indirect object (*me, te, le...*). Literally *me gusta* = "it pleases me".

| | one thing | several things |
|---|---|---|
| I like | me gusta el café | me gustan los perros |
| you like | te gusta | te gustan |
| he/she likes, you (usted) like | le gusta | le gustan |
| we like | nos gusta | nos gustan |
| you (plural) like | os gusta | os gustan |
| they like | les gusta | les gustan |

- With an infinitive always *gusta*: *Me gusta bailar.*
- To stress or clarify the person, add *a* + pronoun or name: *A mí me gusta. A Ana le gustan los gatos.*
- Same pattern: *encantar* (to love: *Me encanta el chocolate*), *interesar* (*¿Te interesa el arte?*), *importar* (*No me importa*), *molestar* (*Me molesta el ruido*), *doler* (*Me duele la cabeza*), *faltar* (*Me falta tiempo*), *parecer* (*Me parece bien*).
