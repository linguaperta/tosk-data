# Can, must, going to: verb + verb

Some verbs are followed by an **infinitive**. Only the first verb is conjugated.

| | poder (can) | querer (want) | deber (must) | saber (know how to) |
|---|---|---|---|---|
| yo | puedo | quiero | debo | sé |
| tú | puedes | quieres | debes | sabes |
| él / ella / usted | puede | quiere | debe | sabe |
| nosotros | podemos | queremos | debemos | sabemos |
| vosotros | podéis | queréis | debéis | sabéis |
| ellos / ellas / ustedes | pueden | quieren | deben | saben |

- *¿Puedes venir?* (Can you come?) *Quiero comer.* *Debes estudiar.* *Sé nadar.* (I can swim.)
- **tener que** + infinitive = to have to: *Tengo que trabajar.*
- **ir a** + infinitive = going to (the near future): *Voy a comer.* *¿Vas a venir?*
- **estar** + gerund (-ando / -iendo) = to be doing right now: *Estoy comiendo.* *¿Qué estás haciendo?* Gerunds: *hablar → hablando, comer → comiendo, vivir → viviendo, leer → leyendo*.
- Pronouns go before the conjugated verb or stick to the infinitive or gerund: *Lo quiero ver* = *Quiero verlo*; *Lo estoy haciendo* = *Estoy haciéndolo*.
