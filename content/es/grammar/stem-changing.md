# Stem-changing verbs: quiero, puedo, pido

In many verbs the vowel of the stem changes when it is stressed. The endings stay regular. **Nosotros** and **vosotros** keep the original vowel, because the stress is on the ending there.

| | e → ie: pensar | o → ue: volver | e → i: pedir |
|---|---|---|---|
| yo | pienso | vuelvo | pido |
| tú | piensas | vuelves | pides |
| él / ella / usted | piensa | vuelve | pide |
| nosotros | pensamos | volvemos | pedimos |
| vosotros | pensáis | volvéis | pedís |
| ellos / ellas / ustedes | piensan | vuelven | piden |

- **e → ie**: *pensar, empezar, cerrar, entender, perder, preferir, sentir* (also *querer*: *quiero*).
- **o → ue**: *volver, dormir, encontrar, contar, recordar* (also *poder*: *puedo*). *Jugar* has **u → ue**: *juego*.
- **e → i** (only -ir verbs): *pedir, repetir, servir, seguir* (*sigo*).
- The dictionary does not show the change: learn it with the verb (*pensar (ie)*, *dormir (ue)*).
