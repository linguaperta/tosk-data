# Present tense of -er and -ir verbs

Verbs in **-er** and **-ir** have almost the same endings. Only *nosotros* and *vosotros* differ.

| | comer (to eat) | vivir (to live) |
|---|---|---|
| yo | como | vivo |
| tú | comes | vives |
| él / ella / usted | come | vive |
| nosotros | comemos | vivimos |
| vosotros | coméis | vivís |
| ellos / ellas / ustedes | comen | viven |

- Compare with -ar verbs: where -ar has **a**, -er/-ir have **e** (*habla – come – vive*).
- *-er* keeps its **e** in nosotros/vosotros (*comemos, coméis*), *-ir* uses **i** (*vivimos, vivís*).
- *Como* also means "like, as": *Como pan* = I eat bread, but *como un niño* = like a child.
- Some verbs change the spelling to keep the sound: *coger → cojo*, *vencer → venzo*.
