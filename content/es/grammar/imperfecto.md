# The imperfect: hablaba, comía

The **imperfecto** describes the past: habits (*used to*), situations, and what was going on when something happened.

| | hablar | comer | vivir |
|---|---|---|---|
| yo | hablaba | comía | vivía |
| tú | hablabas | comías | vivías |
| él / ella / usted | hablaba | comía | vivía |
| nosotros | hablábamos | comíamos | vivíamos |
| vosotros | hablabais | comíais | vivíais |
| ellos / ellas / ustedes | hablaban | comían | vivían |

- Only three verbs are irregular: *ser* (era, eras, era, éramos, erais, eran), *ir* (iba, ibas, iba, íbamos, ibais, iban) and *ver* (veía...).
- *Yo* and *él/ella* have the same form; add a pronoun if needed: *Yo vivía en Lima.*
- Habits: *De niño jugaba al fútbol.* (As a child I used to play football.)
- Description: *Hacía calor y el cielo estaba azul.*
- Background + event: *Leía cuando sonó el teléfono.* (I was reading when the phone rang.) The event is in the indefinido.
