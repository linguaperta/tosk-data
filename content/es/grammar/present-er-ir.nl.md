# Tegenwoordige tijd van -er- en -ir-werkwoorden

Werkwoorden op **-er** en **-ir** hebben bijna dezelfde uitgangen. Alleen *nosotros* en *vosotros* verschillen.

| | comer (eten) | vivir (wonen, leven) |
|---|---|---|
| yo | como | vivo |
| tú | comes | vives |
| él / ella / usted | come | vive |
| nosotros | comemos | vivimos |
| vosotros | coméis | vivís |
| ellos / ellas / ustedes | comen | viven |

- Vergelijk met -ar: waar -ar een **a** heeft, hebben -er/-ir een **e** (*habla – come – vive*).
- *-er* houdt zijn **e** bij nosotros/vosotros (*comemos, coméis*), *-ir* gebruikt **i** (*vivimos, vivís*).
- *Como* betekent ook "zoals, als": *Como pan* = ik eet brood, maar *como un niño* = als een kind.
- Sommige werkwoorden passen de spelling aan om de klank te houden: *coger → cojo*, *vencer → venzo*.
