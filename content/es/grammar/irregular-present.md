# Irregular verbs: tengo, hago, voy

Some very common verbs are irregular. Many are only irregular in the **yo** form:

| yo-form in -go | yo-form in -zco / other |
|---|---|
| hacer → **hago** | conocer → **conozco** |
| poner → **pongo** | dar → **doy** |
| salir → **salgo** | ver → **veo** |
| traer → **traigo** | |

Others change more:

| | tener | venir | decir | ir | oír |
|---|---|---|---|---|---|
| yo | tengo | vengo | digo | voy | oigo |
| tú | tienes | vienes | dices | vas | oyes |
| él / ella / usted | tiene | viene | dice | va | oye |
| nosotros | tenemos | venimos | decimos | vamos | oímos |
| vosotros | tenéis | venís | decís | vais | oís |
| ellos / ellas / ustedes | tienen | vienen | dicen | van | oyen |

- *Tener* is used for age and feelings where English uses "to be": *Tengo veinte años.* *Tengo hambre / frío / miedo.*
- *Ir a* + place: *Voy a la playa.* (*Ir a* + infinitive comes in the next unit.)
- *Conocer* = to know a person or place; *saber* = to know a fact.
