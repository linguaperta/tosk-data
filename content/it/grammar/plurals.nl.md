# Het meervoud

Italiaanse zelfstandige naamwoorden krijgen hun meervoud door de **laatste klinker** te veranderen. Het lidwoord verandert mee (*il → i*, *lo / l' → gli*, *la / l' → le*).

| enkelvoud | meervoud | voorbeeld |
|---|---|---|
| -o (meestal mannelijk) | -i | il libr**o** → i libr**i** |
| -a (meestal vrouwelijk) | -e | la cas**a** → le cas**e** |
| -e (allebei) | -i | il padr**e** → i padr**i**, la chiav**e** → le chiav**i** |
| -a (mannelijk, vaak Grieks) | -i | il problem**a** → i problem**i** |

- **-co / -go** krijgen meestal een *h* om de harde klank te houden: *il lago → i laghi*, *la banca → le banche*. Veel woorden met de klemtoon op de derde lettergreep van achteren niet: *l'amico → gli amici*, *il medico → i medici*.
- **-cia / -gia**: *la camicia → le camicie*, maar *l'arancia → le arance*.
- **-io** met een onbeklemtoonde *i* houdt één *i*: *il figlio → i figli*; met een beklemtoonde *i* twee: *lo zio → gli zii*.
- **Onveranderlijk** blijven woorden op een klinker met accent (*la città → le città*, *il caffè → i caffè*), op een medeklinker (*il film → i film*, *il bar → i bar*) en afkortingen (*la foto → le foto*).
- Een paar onregelmatige: *l'uomo → gli uomini*, *la mano → le mani*, *l'uovo → le uova* (vrouwelijk in het meervoud!).
- Stofnamen zoals *il latte* of *la gente* hebben in deze cursus geen meervoud.
