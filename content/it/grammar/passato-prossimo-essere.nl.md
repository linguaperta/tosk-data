# De passato prossimo met essere

Werkwoorden van **beweging** of **verandering** maken de passato prossimo met **essere**, net zoals het Nederlands *zijn* gebruikt: *Sono andato a Roma.* (Ik ben naar Rome gegaan.) *È diventata medico.* (Ze is arts geworden.)

| | andare | venire | essere |
|---|---|---|---|
| io | sono andato / andata | sono venuto / venuta | sono stato / stata |
| tu | sei andato / andata | sei venuto / venuta | sei stato / stata |
| lui/lei | è andato / andata | è venuto / venuta | è stato / stata |
| noi | siamo andati / andate | siamo venuti / venute | siamo stati / state |
| voi | siete andati / andate | siete venuti / venute | siete stati / state |
| loro | sono andati / andate | sono venuti / venute | sono stati / state |

- Met **essere** past het deelwoord zich aan het onderwerp aan, zoals een bijvoeglijk naamwoord: *Marco è partito*, *Anna è partita*, *siamo arrivati*, *le ragazze sono uscite*.
- Veelvoorkomende essere-werkwoorden: *andare, venire, arrivare, partire, tornare, uscire, entrare, rimanere, restare, stare, diventare, nascere, morire, succedere, piacere, sembrare*, en *essere* zelf.
- *Essere* en *stare* hebben hetzelfde deelwoord **stato**: *Sono stato a casa.* (Ik ben thuis geweest.) Let op: Nederlands *zijn* → *geweest* neemt ook *zijn*.
- *Mi è piaciuto.* = Ik vond het leuk (het is mij bevallen): het deelwoord past zich aan wat je leuk vond aan: *Mi sono piaciute le canzoni.*
- Sommige werkwoorden nemen *avere* met een lijdend voorwerp en *essere* zonder: *Ho passato un esame* (ik ben voor een examen geslaagd) / *Il treno è passato* (de trein is voorbijgekomen).
