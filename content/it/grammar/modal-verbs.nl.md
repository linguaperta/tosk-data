# Modale werkwoorden: potere, dovere, volere, sapere

Deze vier onregelmatige werkwoorden worden meestal direct gevolgd door een **infinitief**: *Posso entrare?* (Mag ik binnenkomen?) *Devo lavorare.* (Ik moet werken.) *Voglio dormire.* (Ik wil slapen.) *So nuotare.* (Ik kan zwemmen.)

| | potere (kunnen, mogen) | dovere (moeten) | volere (willen) | sapere (weten, kunnen) |
|---|---|---|---|---|
| io | posso | devo | voglio | so |
| tu | puoi | devi | vuoi | sai |
| lui/lei | può | deve | vuole | sa |
| noi | possiamo | dobbiamo | vogliamo | sappiamo |
| voi | potete | dovete | volete | sapete |
| loro | possono | devono | vogliono | sanno |

- **potere** = kunnen in de zin van in staat zijn of mogen; **sapere** + infinitief = iets *kunnen* omdat je het geleerd hebt: *Non posso venire.* (Ik kan niet komen.) / *Non so cucinare.* (Ik kan niet koken.)
- **volere** kan ook een zelfstandig naamwoord krijgen: *Voglio un caffè.* Het beleefde "ik zou graag willen" is *vorrei*: *Vorrei un gelato.*
- **dovere** zonder infinitief betekent "schuldig zijn": *Ti devo dieci euro.* (Ik ben je tien euro schuldig.)
- Voornaamwoorden staan vóór het modale werkwoord of hangen aan de infinitief: *Lo posso fare.* = *Posso farlo.* (Ik kan het doen.)
- *Sapere* alleen betekent "weten": *Non lo so.* (Ik weet het niet.)
