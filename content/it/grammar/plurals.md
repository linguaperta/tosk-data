# Plurals

Italian nouns make their plural by changing the **final vowel**. The article changes too (*il → i*, *lo / l' → gli*, *la / l' → le*).

| singular | plural | example |
|---|---|---|
| -o (mostly masculine) | -i | il libr**o** → i libr**i** |
| -a (mostly feminine) | -e | la cas**a** → le cas**e** |
| -e (both genders) | -i | il padr**e** → i padr**i**, la chiav**e** → le chiav**i** |
| -a (masculine, often Greek) | -i | il problem**a** → i problem**i** |

- **-co / -go** usually add an *h* to keep the hard sound: *il lago → i laghi*, *la banca → le banche*. Many nouns stressed on the third-last syllable don't: *l'amico → gli amici*, *il medico → i medici*.
- **-cia / -gia**: *la camicia → le camicie*, but *l'arancia → le arance*.
- **-io** with an unstressed *i* keeps one *i*: *il figlio → i figli*; with a stressed *i* two: *lo zio → gli zii*.
- **Invariable** nouns keep their form: words ending in an accented vowel (*la città → le città*, *il caffè → i caffè*), in a consonant (*il film → i film*, *il bar → i bar*), and short forms (*la foto → le foto*).
- A few irregular ones: *l'uomo → gli uomini*, *la mano → le mani*, *l'uovo → le uova* (feminine in the plural!).
- Mass nouns such as *il latte* or *la gente* have no plural in this course.
