# Onregelmatige toekomende tijd

Een kleine groep heel gewone werkwoorden heeft een aparte **stam** voor de toekomende tijd; de uitgangen zijn de gewone (*-ò, -ai, -à, -emo, -ete, -anno*).

| infinitief | stam | io | noi |
|---|---|---|---|
| essere | sar- | sarò | saremo |
| avere | avr- | avrò | avremo |
| andare | andr- | andrò | andremo |
| potere | potr- | potrò | potremo |
| dovere | dovr- | dovrò | dovremo |
| sapere | sapr- | saprò | sapremo |
| vedere | vedr- | vedrò | vedremo |
| vivere | vivr- | vivrò | vivremo |
| fare / dare / stare | far- / dar- / star- | farò / darò / starò | faremo |
| volere | vorr- | vorrò | vorremo |
| venire | verr- | verrò | verremo |
| tenere | terr- | terrò | terremo |
| rimanere | rimarr- | rimarrò | rimarremo |
| bere | berr- | berrò | berremo |

- Veel ervan laten de klinker voor *-re* weg: *andare → andrò, potere → potrò, vedere → vedrò*.
- Andere krijgen een dubbele *r*: *volere → vorrò, venire → verrò, tenere → terrò, bere → berrò*.
- *Fare, dare, stare* houden hun *a*: *farò, darò, starò* (niet *ferò*).
- *Sarà* drukt ook een vermoeden uit: *Che ore sono? Saranno le tre.* (Hoe laat is het? Het zal wel drie uur zijn.)
