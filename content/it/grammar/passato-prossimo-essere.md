# The passato prossimo with essere

Verbs of **movement** or **change of state** form the passato prossimo with **essere**: *Sono andato a Roma.* (I went to Rome.) *È diventata medico.* (She became a doctor.)

| | andare | venire | essere |
|---|---|---|---|
| io | sono andato / andata | sono venuto / venuta | sono stato / stata |
| tu | sei andato / andata | sei venuto / venuta | sei stato / stata |
| lui/lei | è andato / andata | è venuto / venuta | è stato / stata |
| noi | siamo andati / andate | siamo venuti / venute | siamo stati / state |
| voi | siete andati / andate | siete venuti / venute | siete stati / state |
| loro | sono andati / andate | sono venuti / venute | sono stati / state |

- With **essere** the participle **agrees** with the subject like an adjective: *Marco è partito*, *Anna è partita*, *siamo arrivati*, *le ragazze sono uscite*.
- Common essere-verbs: *andare, venire, arrivare, partire, tornare, uscire, entrare, rimanere, restare, stare, diventare, nascere, morire, succedere, piacere, sembrare*, and *essere* itself.
- *Essere* and *stare* share the participle **stato**: *Sono stato a casa.* (I was / have been at home.)
- *Mi è piaciuto.* = I liked it (it pleased me): the participle agrees with what is liked: *Mi sono piaciute le canzoni.*
- Some verbs take *avere* with an object and *essere* without: *Ho passato un esame* / *Il treno è passato*.
