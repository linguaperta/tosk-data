# Irregular futures

A small group of very common verbs has a special future **stem**; the endings are the regular ones (*-ò, -ai, -à, -emo, -ete, -anno*).

| infinitive | stem | io | noi |
|---|---|---|---|
| essere | sar- | sarò | saremo |
| avere | avr- | avrò | avremo |
| andare | andr- | andrò | andremo |
| potere | potr- | potrò | potremo |
| dovere | dovr- | dovrò | dovremo |
| sapere | sapr- | saprò | sapremo |
| vedere | vedr- | vedrò | vedremo |
| vivere | vivr- | vivrò | vivremo |
| fare / dare / stare | far- / dar- / star- | farò / darò / starò | faremo |
| volere | vorr- | vorrò | vorremo |
| venire | verr- | verrò | verremo |
| tenere | terr- | terrò | terremo |
| rimanere | rimarr- | rimarrò | rimarremo |
| bere | berr- | berrò | berremo |

- Many shorten the infinitive by dropping the vowel before *-re*: *andare → andrò, potere → potrò, vedere → vedrò*.
- Others double the *r*: *volere → vorrò, venire → verrò, tenere → terrò, bere → berrò*.
- *Fare, dare, stare* keep their *a*: *farò, darò, starò* (not *ferò*).
- *Sarà* also expresses a guess: *Che ore sono? Saranno le tre.* (It must be about three.)
