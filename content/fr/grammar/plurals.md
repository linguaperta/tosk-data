# Plurals: chevaux, yeux, bijoux

Most nouns add a silent **-s**: *un livre, des livres*. Some groups are different:

| singular | plural | examples |
|---|---|---|
| -s, -x, -z | no change | *le prix → les prix, la voix → les voix, le nez → les nez* |
| -eau, -eu | + x | *un bateau → des bateaux, un jeu → des jeux* |
| -al | -aux | *un cheval → des chevaux, un journal → des journaux* (but *des festivals*) |
| -ail | -ails (some -aux) | *un détail → des détails*, *le travail → les travaux* |
| -ou | -ous (seven -oux) | *un trou → des trous*; *bijou, caillou, chou, genou, hibou, joujou, pou → -oux* |

- Irregular: *un œil → des yeux*, *le ciel → les cieux* (poetic), *madame → mesdames*, *monsieur → messieurs*.
- Compound nouns vary: *des grands-parents, des après-midi*.
