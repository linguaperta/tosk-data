# Reflexive verbs: je me lève

A reflexive (pronominal) verb has a pronoun that refers back to the subject: *se lever* (to get up), *se coucher* (to go to bed), *s'appeler* (to be called).

| | se lever |
|---|---|
| je | me lève |
| tu | te lèves |
| il / elle | se lève |
| nous | nous levons |
| vous | vous levez |
| ils / elles | se lèvent |

- *me, te, se* become *m', t', s'* before a vowel: *je m'appelle, il s'habille*.
- Negation: *Je ne me lève pas tôt.* Infinitive: the pronoun matches the subject: *Je vais me coucher. Tu dois te reposer.*
- Many are about the daily routine: *se réveiller, se lever, se laver, s'habiller, se coucher*. Others: *se souvenir de* (to remember), *se promener* (to go for a walk), *se dépêcher* (to hurry), *s'amuser* (to have fun), *se tromper* (to be wrong), *se marier* (to get married).
- Plural ones can be **reciprocal**: *Ils s'aiment.* (They love each other.) *Nous nous écrivons.*
