# Irregular participles: fait, dit, pris, vu

Many common verbs have an irregular past participle:

| infinitive | participle | | infinitive | participle |
|---|---|---|---|---|
| être | été | | prendre | pris |
| avoir | eu | | mettre | mis |
| faire | fait | | voir | vu |
| dire | dit | | lire | lu |
| écrire | écrit | | boire | bu |
| ouvrir | ouvert | | connaître | connu |
| pouvoir | pu | | vouloir | voulu |
| devoir | dû | | savoir | su |
| croire | cru | | recevoir | reçu |
| venir | venu | | naître | né |
| mourir | mort | | vivre | vécu |

- *Comprendre, apprendre* go like *prendre* (*compris, appris*); *permettre, promettre* like *mettre*.
- *dû* has a circumflex only in the masculine singular (*due, dus, dues*).
- *été* never agrees: *Elle a été malade.*
