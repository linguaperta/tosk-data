# Irregular futures: je serai, j'irai, je ferai

Some verbs have an irregular future **stem**; the endings are always the same.

| verb | stem | | verb | stem |
|---|---|---|---|---|
| être | ser- | | voir | verr- |
| avoir | aur- | | envoyer | enverr- |
| aller | ir- | | tenir | tiendr- |
| faire | fer- | | venir | viendr- |
| pouvoir | pourr- | | falloir | il faudra |
| vouloir | voudr- | | pleuvoir | il pleuvra |
| devoir | devr- | | courir | courr- |
| savoir | saur- | | mourir | mourr- |

- *Je serai là à huit heures. Nous aurons le temps. Il faudra partir tôt.*
- Spelling changes of the present carry over: *j'achèterai, j'appellerai, je jetterai*.
- The same stems are used in the conditional (unit 13): *je serais, j'aurais, j'irais*.
