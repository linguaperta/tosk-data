# Negation: ne ... pas, jamais, rien, personne

French negation has two parts around the conjugated verb: **ne** (*n'* before a vowel) + a second word.

| | |
|---|---|
| ne ... pas | not: *Je ne parle pas.* |
| ne ... plus | no longer, not any more: *Il ne fume plus.* |
| ne ... jamais | never: *Elle ne ment jamais.* |
| ne ... rien | nothing: *Je ne vois rien.* |
| ne ... personne | nobody: *Je ne connais personne.* |
| ne ... aucun(e) | not a single, no: *Il n'a aucune idée.* |
| ne ... ni ... ni | neither ... nor: *Je n'aime ni le thé ni le café.* |
| ne ... que | only: *Je n'ai que dix euros.* |

- In compound tenses *pas, plus, jamais, rien* go before the participle, *personne* after it: *Je n'ai rien vu. Je n'ai vu personne.*
- *Rien* and *personne* can be subjects: *Personne n'est venu. Rien ne marche.*
- Before an infinitive both parts stand together: *Je préfère ne pas savoir.*
- In everyday speech *ne* is often dropped (*Je sais pas*); write it.
