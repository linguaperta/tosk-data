# Il fut, il eut, il fit: irregular passé simple

| infinitive | il / ils | | infinitive | il / ils |
|---|---|---|---|---|
| être | fut / furent | | voir | vit / virent |
| avoir | eut / eurent | | venir | vint / vinrent |
| faire | fit / firent | | tenir | tint / tinrent |
| dire | dit / dirent | | pouvoir | put / purent |
| prendre | prit / prirent | | savoir | sut / surent |
| mettre | mit / mirent | | vouloir | voulut / voulurent |
| naître | naquit / naquirent | | mourir | mourut / moururent |
| vivre | vécut / vécurent | | écrire | écrivit / écrivirent |

- Many follow the participle: *pris → il prit, mis → il mit, su → il sut, pu → il put, eu → il eut*.
- *Il était une fois un roi qui eut trois filles.* (Once upon a time there was a king who had three daughters.)
- *Ce fut une belle journée.* (It was a fine day.)
