# Je serais, j'aurais, je pourrais

The conditional uses the **same irregular stems as the future**:

| verb | conditional | | verb | conditional |
|---|---|---|---|---|
| être | je serais | | pouvoir | je pourrais |
| avoir | j'aurais | | vouloir | je voudrais |
| aller | j'irais | | devoir | je devrais |
| faire | je ferais | | savoir | je saurais |
| venir | je viendrais | | voir | je verrais |
| tenir | je tiendrais | | falloir | il faudrait |
| valoir | il vaudrait | | | |

- *Ce serait génial ! J'aurais besoin d'aide. Il faudrait partir.*
- *Il vaudrait mieux* = it would be better: *Il vaudrait mieux attendre.*
- *Pourriez-vous ...?*, *Auriez-vous ...?*, *Je voudrais ...* are the polite forms of request.
