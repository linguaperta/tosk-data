# tosk-data

Course content for [tosk](../tosk), a free offline-first language-learning app with a strong
grammar and conjugation focus. Licensed **CC BY-SA 4.0** (see `LICENSE` and `ATTRIBUTION.md`).

```
content/
  it/  nl/
    course.yaml          units, skills, prerequisites, persons, tenses (becomes the skill map)
    seed.yaml            curated vocabulary + gloss overrides (importer input)
    lexicon/*.jsonl      words: one file per unit + pool.jsonl (distractor pool)
    verbs/*.jsonl        full conjugation tables
    sentences/*.jsonl    Tatoeba example sentences, tokenized and aligned to words and verb forms
    grammar/*.md         grammar notes: {skill}.md (English), {skill}.nl.md (Dutch)
    ids.tsv              permanent item ids (append-only)
dist/
  it.sqlite  nl.sqlite   compiled packs (schema: tosk/schema/course_db.sql)
  index.json             id, version, title, sha256, size, schema_version, url (relative to index.json)
```

Italian: greetings, people, essere & avere → food, articles, present tense of -are / -ere / -ire
verbs → time, irregular presents, passato prossimo. Tenses: presente, imperfetto, futuro,
passato prossimo.

Dutch: greetings, people, present tense → food, home, de/het, key verbs (zijn, hebben, modals) →
time, perfectum with hebben, perfectum with zijn. Tenses: tegenwoordige tijd, verleden tijd,
perfectum. Persons: ik, jij, hij/zij, wij, jullie, zij.

## Building

The JSONL files are generated by the pipeline in the `tosk` repository; `course.yaml`,
`seed.yaml` and `grammar/` are edited by hand.

```sh
cd ../tosk
pipeline/.venv/Scripts/python -m pipeline import it nl      # needs `fetch` first (downloads)
pipeline/.venv/Scripts/python -m pipeline build it nl       # validate + compile into dist/ (offline)
```

See `tosk/pipeline/README.md` for the formats, the query language in `course.yaml` and the
alignment rules.
